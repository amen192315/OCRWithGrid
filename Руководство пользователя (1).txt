Руководство пользователя OCR Grid Pro
1. Как запустить программу
1.1. Установка Python
Скачайте и установите Python 3.8 или новее с сайта https://www.python.org/downloads/

При установке отметьте галочку «Add Python to PATH».

1.2. Установка библиотек Python
Откройте командную строку (Win+R → cmd) и выполните команды:

pip install opencv-python
pip install numpy
pip install pillow
pip install pytesseract

1.3. Установка Tesseract OCR
Скачайте установщик с https://github.com/UB-Mannheim/tesseract/wiki

При установке запомните путь установки (по умолчанию C:\Program Files\Tesseract-OCR\tesseract.exe).
На этапе выбора компонентов отметьте языковые пакеты:
1.Russian
2.English

1.4. Настройка пути в коде
Откройте файл программы найдите строку:
pytesseract.pytesseract.tesseract_cmd = r'D:\tesseract\tesseract.exe'

Замените путь на тот, куда установили Tesseract. Если устанавливали по умолчанию, строка будет:
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'

Если все сделано, то можете запускать.

2. Обзор интерфейса
Верхняя панель
Элемент			Назначение
📁 Загрузить  	 	Открыть изображение
📝 OCR + Save   	Распознать текст и сохранить результат в TXT и PNG
💾 Сохранить фото   Сохранить обработанное изображение
Язык 		    Выбор языка распознавания: rus или eng
Сетка	 	    Количество ячеек по горизонтали и вертикали (от 1 до 30)
Режим сетки 	    Треугольники — каждая ячейка из двух треугольников; Квадраты — ячейки из четырёх точек
←   		    Отменить последнее действие с узлами
→     		    Повторить отменённое действие
🔄	                Полный сброс к исходному изображению

Панель фильтров
Элемент			Назначение
Фильтр		Выбор обработки: Оригинал, Ч/Б Адаптив, Инверсия, Резкость, CLAHE Контраст
Яркость		Регулировка яркости от 0.5 до 2.5
Контраст	Регулировка контрастности от -100 до 100
Фильтры 	Влияют только на отображение правой панели и сохранение. Исходное изображение не меняют.

Режимы трансформации
Режим			Описание
🔳 Сетка			Наложение редактируемой сетки. Перемещайте узлы для локального искажения изображения
📐 Перспектива		Исправление перспективных искажений перетаскиванием 4 угловых маркеров
🎛 Геометрия		Произвольная деформация изображения за 4 угла
🔄 Ротация ячеек	Поворот отдельных ячеек на 90°, 180°, 270°
При переключении режима текущий результат становится новым исходником. Кнопка 🔄 возвращает к самому первому изображению.

Панели просмотра
Левая панель (Редактор) — изображение с наложенной сеткой или маркерами
Правая панель (Результат) — результат трансформации с применёнными фильтрами

3. Все клавиши и комбинации
Режим «Сетка»
Действие				Результат
ЛКМ по точке			Выделить одну точку
Ctrl + ЛКМ по точке		Добавить или убрать точку из выделения
Shift + ЛКМ по точке		Выделить все точки между первой выбранной и этой
ЛКМ по линии сетки		Выделить две точки этого ребра
Ctrl + ЛКМ по линии		Добавить две точки ребра к текущему выделению
ЛКМ внутри ячейки		Выделить все углы ячейки
Ctrl + ЛКМ внутри ячейки	Добавить углы ячейки к выделению
Alt + колёсико мыши		Масштабировать выделенные точки относительно их центра
ПКМ				Снять всё выделение
Ctrl + A			Выделить все узлы
Ctrl + Z			Отменить последнее перемещение
Ctrl + Y			Повторить отменённое перемещение

Режим «Перспектива» и «Геометрия»
Действие					Результат
Перетаскивание углового маркера		Изменить положение угла

Режим «Ротация ячеек»
Действие			Результат
ЛКМ по ячейке		Выбрать ячейку
A			Поворот на -90° (против часовой стрелки)
D			Поворот на 90°  (по часовой стрелке)
